## 2. 核心 5 项逐项结论

### 2.1 复跑（项 1）：部分通过
测试/mypy/dev.py/verify_plan 全部与声称一致；唯 `ruff format --check` 在 T06 文件 access.py:48 失败（M1）。

### 2.2 T06-C01—C06 断言真实性（项 2）：基本真实，两处缺口
- 负例真拒绝（独立进程抽样复现，非仅读代码）：伪造 CSRF → CsrfRejectionError("csrf token mismatch")；错误 Origin → "origin not allowed"；跨租户 → CrossTenantAccessError("resource not found")（错误串不含 tenant-alpha/名称）；5 次失败后正确密码 → LoginRateLimitedError("too many login attempts")。pytest.raises 型断言不可能恒真。
- 防账号枚举真实：未知用户与密码错误两次抛 InvalidCredentialsError，断言 `str(...) == str(...)`，实测两串均为 "invalid credentials"，相等成立且区分实现分支。
- C06 正则非恒真：抽样 `api_key = "abcdEFGH1234abcd"` 可命中（证明正则有检出能力）。**但盲区大**：`SECRET_KEY = "..."`（名字含下划线后缀）、JWT（含点号）、含标点或空格的密码（包括测试自带的 "Str0ng-Passphrase!" 形式）均不命中（M2）。
- 边界断言真实性缺陷：`test_cookie_policy_requires_secure_in_production` 仅回显构造参数，不验证 production 强制（M3）；C03 的 forged_request_body 字典未进入任何 API，其中一条断言为字面比较（C3，当前无 HTTP 输入路径，结构性成立）。

### 2.3 安全不变量（项 3）：5/7 成立，2 项缺口
- 成立：请求体自报身份无入口（src 中无直接 `AccessScope(` 构造，唯一入口 build_access_scope 由会话派生）；无默认账号/无公共注册（新目录为空、无 register、add_precreated_user 仅管理路径）；密码仅 Argon2id（实测哈希前缀 `$argon2id$v=`，明文不入哈希）；会话不透明随机（token_urlsafe(32)）+30 分钟过期+注销立即失效（实测）；审计拒绝敏感字段名（实测 AuditEventError）且事件带 trace_id。
- 缺口：production Secure Cookie 无强制机制（M3）；会话明文存储违反合同"服务端保存hash"（M5）。
- 附带发现：`validate_write_request` 不校验过期（实测过期会话仍通过写请求闸门，仅 build_access_scope 拒绝）（C1）；未知用户跳过 Argon2 校验存在时序侧信道（C2）。

### 2.4 代码质量（项 4）：通过
mypy 干净（无 Any/cast/类型忽略掩盖）；异常不吞（`raise ... from None` 为有意去链，非吞异常）；命名/docstring 合规；无万能框架/通用 CRUD 层；IO 与判定分离（时钟可注入）。仅一处格式不合规（M1）。

### 2.5 诚实性（项 5）：有夸大项
- 如实处：in-memory 会话/用户"非生产级"已声明；live=not_run、manual=not_run 如实；E1/F3/X1 未推断优秀档；CR-004 与实现一致（argon2-cffi 依赖、Argon2id、不透明会话、CSRF/Origin、审计脱敏均与代码吻合）；verify_plan --baseline PLAN_OK、冻结未动。

- **M3 production Secure Cookie 无强制、断言恒真**：cookie_secure 仅为构造参数，未与 ApplicationSettings.app_env=production 联动（settings.py 无相关校验）；`test_cookie_policy_requires_secure_in_production` 只回显参数，production 配错也不会失败。T06.md"production Secure Cookie 强制"超出实际。修复：production 强制 secure=True（配置校验/构造期断言）并补负例。
- **M4 admin CLI 不能创建可用账号**：admin_user.py 用一次性 InMemoryUserDirectory，账号随进程退出即丢；两次连跑同名用户均返回 created（重复用户名拒绝与 main() 的 except ValueError 分支永不可达）；以 E:\miniconda\python.exe 直接运行报 ModuleNotFoundError（未记录可用调用方式，实测仅 backend venv 下 `uv run python ..\scripts\admin_user.py` 可用）。修复：持久化或输出可交接载荷 + 记录调用方式；至少在 T06.md 如实声明"CLI 创建结果仅存在于单次进程内"。
- **M5 冻结合同偏离（docs/plan/05 §1，权威高于任务卡，应走变更单或补齐）**：
  1. 角色集缺 `viewer`（合同：viewer/analyst/tenant_admin/system_admin；实现仅 3 角色）；
