# DEC-003 · Goal 持续执行模式：调度方式与授权边界

建立：Goal 执行第 1 轮（主控工程 Agent）｜性质：新增执行记录，不覆盖任何已有文件；原计划、历史报告、冻结合同（AGENTS.md、contracts/baselines/）保持不变。

## 1. 触发依据

项目负责人以 Goal 形式下达持续执行指令：接管 `D:\dianzi` 赛题九项目，从 T00/T01 独立审查开始，持续推进既定工程计划（T00—T59）直到真实完成，以真实测试、独立审查和逐评分项证据证明。该指令取代旧提示词中“只执行单个任务”“单任务完成即停止”“等待用户派发下一任务”的会话级限制。

## 2. 调度方式（本 Goal 采用）

1. 主控 Agent 负责规划、委派、集成、证据检查与持续推进；不以“建议清单”代替执行。
2. 独立审查由主控主动调度独立 subagent 完成（R-Txx）；实现者不得批准自己的实现。审查通过后主控依据审查报告登记状态（accepted），审查未通过则派发修复者做最小修改，再由非修复作者复查实际文件。
3. 任务完成后不机械停止，自动选取下一项（依据 `docs/plan/00_execution_map.md`、`contracts/task_manifest.json` 与任务卡依赖，而非任务编号顺序）。
4. 阶段（G0—G6）完成后由阶段检查 subagent 核查当前阶段约定与全部评分缺口；通过则自动进入下一阶段。
5. 调度信息（活动委派、写入归属、可执行任务、真实阻塞、下一动作）记录在 `progress/goal_state.json`；不修改冻结的 `progress/task_state.json` schema。
6. 主控是 `progress/task_state.json`、`progress/goal_state.json`、`progress/context_handoff.md`、`progress/blockers.md` 的唯一写入者；subagent 只写自己的报告与产物。
7. 委派必须包含：任务/子任务 ID、目标与不做事项、必读文件、冻结输入输出、依赖与资源、允许/禁止写入路径、必须运行的测试、预期产物、报告位置、停止或升级条件。进一步委派须登记在主控可见的任务表。
8. 并发按真实资源与文件写入冲突动态调整：同一文件同一时刻只有一个实现写者；审查者只读被审查代码、只写自己的报告；资源密集测试串行或隔离执行。

## 3. 授权边界（本 Goal 之内）

允许（在实际具备所需权限时执行，不要求系统全局提权）：

- 既定任务卡范围内的本地开发、测试、文档维护。
- 公开官方技术资料核查、正常依赖源访问（控制速率、遵守访问条件）。
- 项目隔离环境中的常规依赖安装（如 T02 的 Python 3.12 + uv 锁文件、T03 的本机 Docker/Compose 开发服务）。
- 本机隔离开发服务的启动与测试（首次启动前检查 Compose 与端口绑定；不改系统默认 Python、不安装未知镜像、不停止其他项目容器）。

不允许：

- 改动官方要求、降低验收标准、改金标或指标分母、删难题、放宽门槛、把失败改 skip。
- 扩大生产或外部资产访问、公开部署、对外扫描或利用、运行下载的 PoC、自动改生产配置。
- 额外付费：新增业务 API、模型、FOFA、云资源及外部计算费用授权为 0；提供者与预算明确前不启用付费或扣配额调用；不下载大模型作无预算替代。
- 远程发布、仓库可见性变更、`git add/commit/push/fetch`（本 Goal 不新增该授权）、`reset --hard`、`clean -fd`、force push、删除用户文件。
- 秘密值的读取、输出、写入报告/提示词/日志/前端；仅可记录配置是否存在。

## 4. 事实与证据不变量（延续 AGENTS.md）

- 未知不等于否定；线索不等于确认；引文存在不等于内容支持；模型假设不等于事实；外部不可达不等于已修复；静态 PoC 核查不等于运行验证；当前结论不等于历史结论。
- 未实际执行的检查一律 `not_run`；不伪造测试数量、准确率、性能、连续运行时长、外部对照、人工复核或预计得分。
- 合成样例、测试替身、离线回放与真实运行明确隔离；20 个合成案例（`fixtures/synthetic/pilot_cases.json`）为待复核提案，独立 Agent 审查不等于人工金标审批。
- `blocked_live` 仅作叙述标签，机器可读状态遵守冻结枚举（verification.live 用 `blocked` 或 `not_run` 并注明原因）。
- PostgreSQL 为事实与任务状态权威；不另建业务真相；不擅自更换既定技术栈。
