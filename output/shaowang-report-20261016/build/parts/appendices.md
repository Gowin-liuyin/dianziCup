{{A-1}}

CNVD 的处理是降为加分项并保留人工导入，不做验证绕过；CNNVD 成为国内主力候选，但具体数据接口仍待确认。arXiv 改以 RSS 为主，export API 补漏，其他渠道备用。这里的方案调整发生在观测之后，不能倒写成失败入口已修复。Hunter 首页同样不能替代业务 API 测试，FOFA 的积分不足也不是网络不可达。

第二轮补充发生在 2026-10-15 15:57 的境外环境。arXiv RSS 为 200，Semantic Scholar bulk 为 429，avid-db 仓库为 200，Hunter 首页为 403。它们用于解释备用通道与环境差异，不覆盖第一轮境内结论；尤其不能用境外 RSS 成功删除境内 RSS 待测项。

{{A-2}}

材料还记录了 2026-10-14 境外多个来源接口、仓库和页面返回 200，以及 AVID API 403、Protect AI 和 HiddenLayer RSS 404。不同入口属于不同能力：仓库可读不等于 API 可用，网页可打开不等于数据解析完整。复测时需要逐入口登记，而不能只在“平台可用”一栏打钩。

补证据应保留时间、网络环境、公开入口、状态码、结论和处置，并保存脱敏后的原始响应摘要。境内计划复跑 cn-network-test.sh；本次重写没有执行网络复测。记录文件、采集时刻与哈希前十二位为【实录待补】。若复测变化，应新增一行记录，保留旧结果，而不是改写历史响应。

{{B-2}}
